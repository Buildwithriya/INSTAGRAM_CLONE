🎯 Project Objective
The primary objective of this project is to understand and implement the fundamental concepts of:

👉GUI Development: Designing a responsive and intuitive user interface.

👉Database Handling: Managing user profiles, post data, and interaction logs.

👉Event-Driven Programming: Implementing logic that responds to user actions like likes, comments, and uploads.

It serves as a practical demonstration of how social media applications manage user interactions, data persistence, and interface design.

🚀 Core Features
1. User Authentication & Profile Management
Secure Access: Implemented logic for user signup and login sessions.

Personalization: Custom user profiles including bios and post history.

2. Media Interaction & Feed
Real-time Post Creation: Users can upload images with captions that immediately populate the feed.

Engagement Logic: Integrated "Like" and "Comment" systems that update data states without full-page refreshes.

3. Data Persistence
Ensures that all user interactions (likes, new posts, profile updates) are saved and remain available after the application is closed.

🛠️ Technical Stack

Layer.....Technology.....Purpose
Frontend.....Python (Tkinter)
"Developing the Graphical User Interface (GUI), including windows for the feed, login, and post uploads."

Data Layer...SQL (SQLite/MySQL)
"Managing persistent storage for user credentials, post metadata, and follower relationships."

Business Logic...Python
Implementing the core engine that connects the GUI events to database queries and handles data processing.
